# Security · الأمان

Mivtra Craft is text (skills) plus one installer script, `install.ps1`.

- The installer downloads only `https://github.com/mivtra/craft/releases/latest/download/mivtra-craft.zip`,
  checks it is a valid plugin, and writes only to `~/.claude` (and to Downloads with `-Zip`).
  It needs no administrator rights and sends nothing anywhere.
- Read it before running it: https://github.com/mivtra/craft/blob/main/install.ps1

Report a security problem privately to **info@mivtra.com**, not in a public issue. You will get an
answer within 72 hours.

أبلغ عن أي مشكلة أمنية على **info@mivtra.com** لا في بلاغ عام، والرد خلال 72 ساعة.
